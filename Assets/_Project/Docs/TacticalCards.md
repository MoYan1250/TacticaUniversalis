# 戰術卡規格

## 回合規則

- 每隊使用 6 張通用卡與 6 張隊伍專屬卡。每回合抽 2 張；牌庫空時重洗棄牌堆。
- 手牌上限 7，一回合最多打出 3 張。抽牌造成的溢出可暫留，但鎖定回合前必須棄到 7 張。
- 指揮點開局 6；換邊 +3；每個加時半場 +2；上限 10 並跨回合保留。
- 同回合多卡加總上限：首殺 30%、火力 20%、配合 15%、殘局 15%。

## 通用卡

- **穩扎穩打（0）**：沒有明顯加成的 Mid 默認控圖。適合局勢不明與存點；不適合必須立即翻盤。
- **ECO 絕境快攻（1）**：Eco/Light 的高風險 B Rush。適合低裝爆冷；不適合完整裝備或撞紀律防守。
- **激進前壓（2）**：A Long 主動搶首殺。適合突破手狀態佳；不適合對手資訊充分或嚴格架槍。
- **中路情報網（1）**：爭奪 Mid 視野並揭示對手主類型。適合抓 Rush/前壓；不提供直接火力突破。
- **聲東擊西（2）**：A 假打後轉 B，或 B 假打後轉 A。適合破解集中賭防；不適合對上紀律與老將讀局。
- **戰術調整（1）**：雙方鎖定後查看分析並替換一張本回合已選卡。適合修正錯配；不適合 CP 緊張時空耗。

## NAVI 2021

- **神狙支點（3）**：以 s1mple 為 A Long 防線核心。適合 AWP 完整且狀態佳；不適合 Ax1Le 類自由人。s1mple 陣亡後本回合全隊火力 -8%。
- **雙星破陣（3）**：s1mple 與 electronic 同步進攻 A Site。適合正面破點；不適合撞鐵壁。
- **新星試煉（1）**：低費讓 B1T 主打首戰。適合節省 CP；B1T 陣亡使下回合全隊火力 -5%。
- **完美殘局（2）**：只在 Perfecto 存活的 Clutch 生效。適合預期拉長回合；不適合需要前期優勢。
- **Boombl4 調度（1）**：立即額外抽 4 張，但本回合火力 -5%。適合補充選擇；不適合必勝局或手牌已滿。
- **鋼鐵紀律（2）**：保守交叉火力，克制 Rush、前壓與欺騙；對耐心默認控圖略不利。

## Gambit 2021

- **紅星同步（2）**：以滿額配合加成執行穩定正面戰術。適合完整裝備；不適合需要非常規翻盤。
- **sh1ro 穩健架槍（2）**：降低 sh1ro 前期暴露並強化後段。適合 AWP 控場；不適合落後追分。
- **nafany 親征（2）**：nafany 優先參與首戰的高風險 Rush。適合打亂默認；nafany 陣亡後失去本卡配合加成。
- **Hobbit 老將讀局（2）**：每場最多 2 次；揭示對手全部已選卡並將其卡牌數值削弱 40%。適合破解欺騙與高費組合。
- **Ax1Le 無聲滲透（2）**：避開首輪正面接觸，後段繞過 stack/賭防。適合對手集中防守；不適合資訊控制。
- **紅星鐵壁（3）**：最強紀律防守，克制全部激進類型；對默認控圖過於被動。

## 相剋矩陣

行為我方、列為對手；`++` 為火力與首殺各 +10%，`+` 為火力 +5%，`0` 為均勢，負號為對手取得對應優勢。

| 我方＼對手 | balanced | rush | aggressive | info | deception | stack | discipline | tactical |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| balanced | 0 | -- | -- | 0 | 0 | 0 | + | 0 |
| rush | ++ | 0 | 0 | -- | ++ | -- | -- | 0 |
| aggressive | ++ | 0 | 0 | -- | 0 | -- | -- | 0 |
| info | 0 | ++ | ++ | 0 | 0 | 0 | 0 | 0 |
| deception | 0 | -- | 0 | 0 | 0 | ++ | -- | 0 |
| stack | 0 | ++ | ++ | 0 | -- | 0 | 0 | 0 |
| discipline | - | ++ | ++ | 0 | ++ | 0 | 0 | 0 |
| tactical | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

專屬覆寫：

- Hobbit 老將讀局對所有 deception 為 `++`，並額外削弱卡牌數值 40%。
- Ax1Le 無聲滲透對所有 stack 為 `++`。
- NAVI 鋼鐵紀律、紅星鐵壁對 rush/aggressive/deception 均為 `++`。

所有 18×18 對局由卡牌 archetype 套用上表，再套用專屬覆寫，因此隊伍專屬卡之間也使用同一套可驗證規則。
